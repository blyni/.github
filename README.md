# .github

Repositorio de perfil de la organización [Blyni](https://github.com/blyni).

| Ruta | Contenido |
|---|---|
| `profile/README.md` | La presentación que GitHub muestra en la página de la organización. |
| `profile/marca/` | Copias sin cambios del logotipo, la mascota y la paleta, tomadas del kit de marca (`blyni-marca`). GitHub no muestra en un README imágenes de un repositorio privado, por eso viven aquí. |

## Cómo se actualiza

- Los archivos de `profile/marca/` no se editan: si la marca cambia en `blyni-marca`, se vuelven a copiar tal cual, con el mismo nombre.
- Los colores y la tipografía que menciona el perfil salen de `07-colores-y-tipografia/paleta.json` del kit; si cambian allí, se actualiza la tabla del perfil.
- Cada cambio entra por una rama y un pull request contra `main`, un archivo por commit.
